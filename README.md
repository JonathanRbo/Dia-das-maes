# Para a Angélica 💗

Um site de Dia das Mães feito com carinho, do filho pra mãe.

> *"Tem coisa que mãe não ensina com palavras. Ensina pelo jeito que vive."*

## Sobre

Página estática em HTML/CSS/JS criada como homenagem para a minha mãe, **Angélica**, no Dia das Mães. Conta um pouquinho da nossa história em fotos e palavras.

## Como ver

Abra o arquivo `index.html` no navegador, ou acesse a versão publicada no GitHub Pages.

## Estrutura

```
dia-das-maes/
├── index.html           # Estrutura da página
├── styles.css           # Estilo (paleta romântica/floral)
├── script.js            # Animações, lightbox e pétalas
├── images/              # Fotos da galeria (foto1.jpg → foto7.jpg)
└── instagram-post.webp  # Arte para divulgação no Instagram
```

## Tecnologias

- HTML5 + CSS3 (sem frameworks)
- [AOS](https://michalsnik.github.io/aos/) — animações ao rolar
- [GLightbox](https://biati-digital.github.io/glightbox/) — galeria em tela cheia
- Google Fonts: *Playfair Display*, *Cormorant Garamond*, *Dancing Script*

## Seções

1. **Hero** — homenagem com nome e foto principal
2. **Mensagem** — recado do coração
3. **Galeria** — 6 fotos clicáveis com lightbox
4. **Citação** — frase em destaque
5. **Razões** — qualidades dela em três cartões
6. **Carta** — mensagem final, simples e direta

## Créditos

Feito com 💗 por um filho grato.
